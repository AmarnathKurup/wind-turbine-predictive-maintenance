# Data

**Nothing in this folder is committed to Git** (see `.gitignore`).

The original **CARE to Compare v6** dataset is kept outside the project at `..\CARE_To_Compare` and is only
ever read (verified unchanged after inspection). It is not redistributed here; obtain it from its original source.

`processed/` is generated by `python -m wtpm.preprocessing` (≈3.8 GB) and can be deleted and rebuilt:

| File | Contents |
|---|---|
| `records.pkl` | 1,806,551 deduplicated Farm C records: `_avg` + `_std` features, label, label_source, fold, asset_id, ts |
| `event_windows.pkl` | 120,080 rows: every event window on its own file timeline (event-level evaluation) |
| `fold_assignment.csv` | turbine → fold |
| `preprocessing_config.json` | all settings used |
